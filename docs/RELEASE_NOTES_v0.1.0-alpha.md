# OMNI-X v0.1.0 Alpha

## Included

- Windows Tauri desktop with a managed Python backend sidecar.
- Authenticated loopback IPC, process ownership, recovery and clean shutdown.
- CLI and SQLite-backed sessions, memory, tasks, workflows and approvals.
- Brain canvas, semantic-style local search, document extraction and governed
  memory suggestions.
- Local-first voice controls, reviewed skills, MCP boundary controls and
  credential-scoped integration adapters.
- Free-first routing, FREE-mode enforcement and bounded context optimisation.

## Validation

Hosted Windows run `45510089296` passed installer, launch, sidecar,
authenticated health, crash recovery, shutdown and silent uninstall. Hosted CI
and security run `45510089397` and `45510089307` passed. The installer is
unsigned and live provider inference is not guaranteed.

## Known limitations

Live Hermes tool execution/delegation, Council, external account connections,
physical voice hardware and optional local model engines remain experimental or
configuration-dependent. No production release is being published from this
alpha candidate.
