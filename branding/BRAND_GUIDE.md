# OMNI-X brand guide

OMNI-X is a professional, open-source Windows-first AI desktop application.
The visual language is minimalist, technical and calm: strong black/white
contrast, restrained motion and a recognisable pixel-inspired X.

## Palette

| Token | Value | Use |
|---|---|---|
| Ink | `#0B0D10` | Dark surfaces and wordmark |
| Paper | `#F7F7F5` | Light surfaces and reversed lockups |
| Line | `#2A2F36` | Borders and dividers |
| Muted | `#9AA1AA` | Secondary text |
| Signal | `#55D6BE` | Optional success/accent state |
| Alert | `#F5B971` | Warnings requiring attention |

Maintain a minimum 4.5:1 text contrast ratio. Use Signal and Alert as status
accents, never as the sole indication of a permission or security decision.

## Typography and layout

Use the desktop system sans-serif stack for interface text. Use a restrained
monospace face only for model identifiers, tool traces and terminal output.
Prefer 8px spacing increments, generous whitespace and one primary action per
surface.

## Motion and incorrect use

Motion should communicate loading, progress, completion or recovery. Keep it
short and respect `prefers-reduced-motion`. Do not stretch or rotate the mark,
add gradients or shadows, place it over busy imagery, or use Hermes, OmniRoute
or provider logos as if they were OMNI-X components.
