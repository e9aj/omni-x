# OMNI-X website content package

This copy is prepared for the existing website and is not deployed by this

## Hero

**OMNI-X**  
One Agent. Every AI. Infinite Possibilities.

A free, open-source AI desktop application for secure, model-flexible agent
workflows on Windows.

## Verified alpha message

The Windows alpha includes an authenticated desktop shell, managed Python
backend, SQLite persistence, Brain tools, workflow controls, approvals and
free-first routing. Hosted Windows validation covers installation, startup,
backend health, crash recovery, shutdown and uninstall.

## Be precise about availability

Live model responses depend on a legitimate configured provider or local model.
Hermes execution, tool calling, delegation, Council, voice engines, MCP
servers and external accounts are experimental or configuration-dependent.
OMNI-X never invents credentials, bypasses provider authentication or silently
selects paid inference.

## Calls to action

- Download the Windows alpha after verifying its checksum.
- Read the installation and security documentation.
- Inspect the source and integration register on GitHub.
- Report reproducible defects without including secrets or private data.

Remove pricing, subscription and unsupported performance claims from the live
site. Use genuine screenshots only; do not present simulated responses as live
AI evidence.
