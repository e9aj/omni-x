# Code of Conduct

Contributors are expected to be respectful, constructive and inclusive. Do not
harass, discriminate, threaten, expose private information, or use the project
to bypass authentication, provider safeguards or legal requirements.

Maintainers may remove contributions or restrict participation when behaviour
is unsafe, abusive or inconsistent with the project security baseline. Report
security issues privately using `SECURITY.md` rather than opening a public
issue.
